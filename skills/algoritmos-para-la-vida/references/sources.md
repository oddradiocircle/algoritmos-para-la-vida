# Fuentes públicas

Esta bibliografía identifica las referencias técnicas y de contexto usadas para
orientar las fichas del catálogo. Los identificadores entre corchetes son
referencias del catálogo, no una escala de calidad. Las fuentes secundarias
aportan contexto; las afirmaciones formales deben contrastarse con la fuente
primaria correspondiente.

Los enlaces de búsqueda se conservan solo para referencias contextuales cuyo
localizador estable no quedó identificado; no deben tratarse como evidencia
primaria. Las afirmaciones de salud, derecho, finanzas, seguridad, empleo,
vivienda u otros asuntos de alto impacto requieren fuentes actuales y
especializadas.
