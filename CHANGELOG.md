# Changelog

Todos los cambios relevantes de este proyecto se documentan en este archivo.

El formato sigue las convenciones de [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/), y las versiones usan [Versionado Semántico](https://semver.org/lang/es/).

## [Unreleased]

### Cambiado

- Reorganizado el README alrededor de entender, instalar, probar y profundizar.
- Añadidos enlaces directos al ZIP, al skill y al catálogo.
- Documentadas las rutas de instalación para ChatGPT, Claude, Hermes y agentes
  compatibles con `skills.sh`.
- Simplificadas las instrucciones de instalación y priorizada la ruta estándar
  de `npx skills`.

## [0.2.0] — 2026-09-20

Actualización de distribución e instalación para agentes y aplicaciones de
escritorio.

### Añadido

- Instrucciones de instalación para Claude Desktop, ChatGPT, Hermes Desktop,
  Claude Code, Hermes Agent, Codex y otros agentes compatibles.
- ZIP universal para cargar el skill en Claude Desktop y ChatGPT.
- Integración opcional como marketplace de Claude Code mediante
  `.claude-plugin/marketplace.json`.
- Nota de inspiración y atribución al libro *Algorithms to Live By*, de Brian
  Christian y Tom Griffiths.

## [0.1.0] — 2026-09-20

Primera publicación pública de **Algoritmos para la vida**.

### Añadido

- Skill distribuible mediante `skills.sh`.
- Catálogo de heurísticas para elección, parada, tiempo, atención, aprendizaje,
  exploración, relaciones y recursos.
- Entrevista guiada, consulta directa del catálogo y análisis de casos.
- Respuestas ejecutivas con hechos, supuestos, inferencias, recomendaciones,
  límites y puntos de revisión.
- Salvaguardas para decisiones de alto impacto.
- Evaluaciones manuales y plantilla de análisis de caso.
- Referencias técnicas y bibliografía pública.
- Metadatos de compatibilidad para agentes mediante `agents/openai.yaml`.

### Documentación

- README con instrucciones de instalación, ejemplos y límites de uso.
- Licencia MIT.
